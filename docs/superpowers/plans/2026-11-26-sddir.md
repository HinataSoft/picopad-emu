# SD karta ze složky (`--sddir`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `GAME.exe --sddir DIR` (okno i headless) dá hře kartu FAT s obsahem složky DIR, obraz drží jen v paměti (řídce) a při jakémkoli ukončení emulátoru promítne souborový systém z obrazu zpět do DIR.

**Architecture:** Tři čisté C vrstvy v `platform/` bez SDK a SDL: `sparsedisk` (řídké sektorové úložiště v paměti), `fatvol` (vlastní FAT32 formátovač, zapisovač a čtečka nad sektorovým I/O), `sddir` (import složky → fatvol, manifest, synchronizace zpět podle pravidel návrhu). Nad nimi `sdcard` – jediné místo, kam míří `plat_sd_*` z `main.cpp`: buď stávající `sdimage` (`--sd`), nebo `sparsedisk` pod zámkem (`--sddir`), plus idempotentní `sdcard_shutdown()` volané na všech cestách ukončení. Shodu s `lib_fat` hlídají křížové testy proti `picopad-sdimg` a end-to-end test se skutečnou `lib_fat` ve hře.

**Tech Stack:** jako M3 – WinLibs GCC 16.2 i686, SDL2, CMake + Ninja, CTest; Win32 API pro soubory ve `sddir.c`/`sdcard.c` (platformní strana smí `windows.h`). Nic nového se nestahuje.

**Spec:** docs/superpowers/specs/2026-11-26-sddir-design.md (celý). Kontext: docs/superpowers/specs/2026-11-23-picopad-emulator-design.md (část SD karta), plán M3 docs/superpowers/plans/2026-11-26-picopad-emu-m3.md (Task 4–5: `sdimage`, `picopad-sdimg`, SDTEST).

**Výchozí stav (main 91b9811):** `platform/main.cpp:164-167` implementuje `plat_sd_*` přímo nad `sdimage_*` (okno i headless); `--sd` se otevírá v `main()` (`platform/main.cpp:340`), zavírá v `finish()` (`:294`) a po `headless_run` (`:355`). ## Global Constraints

- PicoLibSDK se nemění; `lib_fat` hry čte obraz po sektorech přes `plat_sd_*` jako dnes. `include/plat_api.h` se nemění.
- `sparsedisk.c` a `fatvol.c` jsou čisté C bez SDL, bez `windows.h` a bez SDK hlaviček; `sddir.c` a `sdcard.c` smí `windows.h`, ne SDL ani SDK.
- Velikost karty pro `--sddir` je pevně 1 GiB = 2097152 sektorů po 512 B. Blok řídkého úložiště je 64 KiB (128 sektorů); blok se alokuje až při zápisu nenulových dat, nealokovaný blok se čte jako nuly.
- FAT32 s MBR (jedna partition), stejné rozložení jako `DiskFormat(FS_FAT32, clust, True, …)` z `lib_fat`; cluster začíná na 32 sektorech a půlí se, dokud počet clusterů není ≥ 65525 (jako `picopad-sdimg`).
- Jména: každý segment cesty musí projít stejnými pravidly jako `fo_check_name` (znaky `A-Z a-z 0-9 !#$%&'()-@^_\`{}~`, základ 1–8, přípona 0–3, nejvýš jedna tečka, ne na začátku ani na konci); malá písmena se ve FAT uloží velkými. Neplatné jméno → nenahraje se (ani nic pod ním), varování na stderr, synchronizace na ně nikdy nesáhne.
- Čas změny: host mtime → FAT datum/čas v místním čase (2 s rozlišení) a zpět.
- `--sd` a `--sddir` se vylučují → kód 2. DIR neexistuje / není složka / obsah se nevejde do 1 GiB → kód 2 se srozumitelnou hláškou na stderr. Ostatní ukončovací kódy beze změny (0 quit/exit, 1 fatal, 2 argumenty, 3 max-time).
- Synchronizace běží při každém ukončení (hra sama, zavření okna, Ctrl+C, `quit`, `--max-time`, watchdog, fatal; okno i headless), právě jednou, se zamčeným obrazem. Chyby synchronizace = varování na stderr, exit kód se nemění.
- Pravidla synchronizace (návrh, část Synchronizace zpět): nový/změněný → zapsat (existující soubor pod stávajícím host jménem, nový jménem z FAT), smazaný a při startu nahraný → smazat (složku jen prázdnou, jinak varování), host změněný od startu (velikost nebo mtime) a hra ho změnila/smazala → nesahat + varování; nový soubor v obrazu, jehož cesta v DIR mezitím vznikla → nesahat + varování.
- Determinismus headless z M2/M3 platí dál; existující testy (`sd_image`, `sdimg`, reference PNG) beze změny procházejí.
- Varování mají tvar `<GAME>: --sddir: <text>` na stderr (`<GAME>` = `PICOPAD_GAME_NAME`; v pomocném nástroji testů název nástroje).

```c
typedef struct {
    void* ctx;
    unsigned int sectors;
    int (*read)(void* ctx, unsigned int sector, unsigned char* buf512);         /* 1 ok */
    int (*write)(void* ctx, unsigned int sector, const unsigned char* buf512);  /* 1 ok */
} fatvol_io;
typedef struct { unsigned short date, time; } fat_stamp;   /* FAT-encoded, local time */
typedef struct fatvol fatvol;

/* MBR + one FAT32 partition, layout as lib_fat DiskFormat(FS_FAT32, clust, True, ...):
   clust starts at 32 sectors, halved until clusters >= 65525; error if not reachable. */
fatvol* fatvol_format(const fatvol_io* io, char* err, int errlen);
/* mounts an existing FAT32 volume (MBR partition or superfloppy); other FAT types -> NULL + err */
fatvol* fatvol_open(const fatvol_io* io, char* err, int errlen);
const char* fatvol_error(const fatvol* v);         /* last error message */
void fatvol_close(fatvol* v);                      /* writes FSInfo (free count, next free), frees */

/* paths: uppercase 8.3 segments separated by '/', no leading '/', root = "" */
int fatvol_mkdir(fatvol* v, const char* path, fat_stamp t);                 /* 0 ok; parent must exist */
int fatvol_file_begin(fatvol* v, const char* path, unsigned int size, fat_stamp t); /* 0 ok; reserves contiguous clusters; "SD card full" if no room */
int fatvol_file_write(fatvol* v, const void* data, unsigned int n);          /* 0 ok; sum of n must equal size */
int fatvol_file_end(fatvol* v);                                              /* 0 ok */
int fatvol_delete(fatvol* v, const char* path);   /* 0 ok; file or empty dir: entry 0xE5, chain freed */

typedef struct {
    const char* path;          /* as above, valid during the callback */
    int is_dir;
    unsigned int size;
    fat_stamp stamp;           /* write date/time */
    unsigned int first_cluster;
} fatvol_entry;
/* pre-order walk (a directory before its contents); skips ".", "..", volume label,
   deleted and LFN entries. cb returns 0 = go on, nonzero = stop (returned). -1 = read error / bad chain. */
int fatvol_walk(fatvol* v, int (*cb)(void* ctx, const fatvol_entry* e), void* ctx);
/* follows the cluster chain of a file; sink returns 0 = go on. -1 = bad chain / read error. */
int fatvol_read_file(fatvol* v, const fatvol_entry* e,
                     int (*sink)(void* ctx, const void* data, unsigned int n), void* ctx);
```

**Interfaces:**
- Consumes: Task 1–3; `sdimage_*` (`platform/sdimage.h`).
- Produces:
```c
/* cli_options */ const char* sddir;   /* --sddir DIR (points into argv), NULL = none; with --sd -> CLI_ERROR */
/* platform/sdcard.h */
int  sdcard_open_image(const char* path, char* err, int errlen);   /* --sd; 0 ok, -1 err */
int  sdcard_open_dir(const char* dir, const char* game_name, char* err, int errlen); /* --sddir; 0 ok, -1 err (exit 2); warnings "<game>: --sddir: ..." on stderr */
```
